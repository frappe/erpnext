# ExportHub-ERP

Custom ERP system for wooden handicrafts export business.

## About
Built with Django/Python for export-focused wooden products company.
Handles Purchase, Sales, Inventory, Production, Finance & Export documentation.

## Features
- Multi-currency support
- GST/Export duty calculations
- Shipping documentation
- Quality management
- International order tracking

## Tech Stack
- Backend: Python Django
- Database: PostgreSQL
- Frontend: React/Vue
- Deployment: Docker
